# Al Shabana Typing & Travels

Static demo website for **Al Shabana Typing & Travels** (Al Shabana Typing Center & Studio) in Al Sila, Abu Dhabi.

## Open locally

No build step or package install is required.

1. Open `index.html` in a browser, or
2. Serve the folder with any static host (for example, the Live Server extension).

Pages:

- `index.html` — Home
- `services.html` — Service directory
- `service-details.html?service=visit-visa` — Service detail template
- `about.html` — About
- `contact.html` — Contact, hours, map, WhatsApp form

## Update business information

Edit the `BUSINESS` object and WhatsApp `MESSAGES` in `assets/js/main.js`.

Also update matching text in the HTML pages (header, footer, contact details, and hours) so the site still works if JavaScript is disabled.

Service copy for the details page lives in the `SERVICES` object in the same JavaScript file.
